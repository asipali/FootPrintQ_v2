How FootprintIQ Works

A disciplined, ethical three-step workflow designed for security teams and authorized lab evaluations.

1

Define Target Scope

Create a new investigation, register owned domains, define approved IP and CIDR ranges, and generate time-bounded target authorization records.

2

Execute Permitted Assessments

Execute automated passive domain reconnaissance and run authorized active network scans strictly within permitted scope boundaries.

3

Review Evidence & Report

Examine structured findings, inspect raw evidence provenance hashes, analyze audit trails, and export consolidated PDF or GraphML reports.

Authorization Enforcement: Passive reconnaissance permissions do not authorize active network or vulnerability scans. All active scanning requires explicit target authorization records.

Security & Responsible Use Principles

Engineered with strict access control, scope enforcement, and verified integrity guarantees.

Role-Based Access Control

Enforces least-privileged access across Administrator, Security Analyst, and Viewer roles with server-side validation on all endpoints.

Target-Scope Boundaries

Subprocess and active scan execution is strictly gated by verified scope membership and active target authorization records.

Evidence Provenance & Auditing

Raw evidence records are stamped with SHA-256 integrity hashes, collector timestamps, and immutable audit logs.

Cryptographic Protections

Passwords hashed with RFC 9106 Argon2id; browser sessions secured with 256-bit entropy tokens and constant-time CSRF defenses.

Responsible Use Standard

Designed strictly for authorized cybersecurity investigations, educational labs, and self-hosted defense assessments.
